# common/ — shared C++ header

`hd_common.h`: F_p arithmetic, the one-digit certificate of `lem:cert` (j = 1), window coverings and the record reader
for general s, used by `selection_rule/steer_rule.cpp` and `selection_rule/hv_dump.cpp`. No check of its own; it is
compiled as part of those programs (see `selection_rule/README.md`).
