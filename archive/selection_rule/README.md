# selection_rule/ — the greedy selection rule and the staggered window system of Figure `fig:bsgeom`

Supports: the rule of `rem:steerrule` (deterministic choice among the admissible own values, `prop:depthdir` +
`prop:LI`(c); any admissible choice keeps the window certificate by `prop:steer`), applied to the archived staggered
window system at p = 101 of Figure `fig:bsgeom`. Not a computer-assisted proof item: the rule changes only the actual
point set, never the certified bound.

Files:
* `cfg/bs_s3_p101.cfg` — the staggered window system of Figure `fig:bsgeom` (s = 3, p = 101, places 0, 1, 79, θ = 60;
  record format `verify/README.md`): certified sep(P_{3K}) ≥ 52/101 = 0.5148 for every K, checked by
  `verify/verify_designs.py` (see `verify/README.md`). Converted from the research build format by `bs2steer.py`, with
  the exact bound added as a `minS` line.
* `steer_rule.cpp` (uses `common/hd_common.h`) — steering with deterministic selection. Mode `lb1` is the rule of
  `rem:steerrule`: at depth 1 maximise the exact `lem:cert` (j = 1) certificate of the actual level-1 responses over all
  combinations of admissible own values (ties: most central, then larger own value, columns in order); deeper: most
  central admissible own value. Other modes (`cenhi`, `cenlo`, `near0`, `psimin`, `force:...`) are the rules compared
  in `rem:steerrule`.
* `hv_dump.cpp` (uses `common/hd_common.h`) — rebuilds the generator matrices from the steered law, checks the direct
  level-K law against the steering and t = 0, and dumps the matrices; `bs_mind.cpp` (+ `bs_common.h`) — exact minimum
  distance of P_3 from a dump.
* `bs2steer.py` — converts a brick-star record of the research build programs to the record format (not needed for the
  check).

## Re-run (from the archive root)

    python3 verify/verify_designs.py selection_rule/cfg/bs_s3_p101.cfg
    mkdir -p bin && g++ -O2 -std=c++17 -o bin/steer_rule selection_rule/steer_rule.cpp && g++ -O2 -std=c++17 -o bin/hv_dump selection_rule/hv_dump.cpp && g++ -O2 -std=c++17 -o bin/bs_mind selection_rule/bs_mind.cpp
    ./bin/steer_rule selection_rule/cfg/bs_s3_p101.cfg 40 bin/x lb1
    ./bin/hv_dump bin/x 3 1,2 6 0 8 3 bin/x_dump.txt
    ./bin/bs_mind bin/x_dump.txt

Expected: `## TOTAL 1/1 PASS` (LB = 0.514851); `lb1: depth-1 actual LB_1 = 0.634977`, `never stuck, violations 0`;
`27/27 law responses agree; t=0 rank-deficient compositions: 0`; `R=8 digits: net(one point per cell)=yes
sep(P_3) = 0.642510`. So the rule gives sep(P_3) = 0.6425 ≥ LB_1 = 0.6350 ≥ 0.5148 for this system. The point set
shown in Figure `fig:bsgeom` is another admissible choice of the free digits (exact sep(P_3) = 0.6416, as stated in
its caption); it was generated by a research program and is not archived.

Not archived: the comparison of 35 cases quoted in `rem:steerrule` (research runs; the modes above re-run any case),
the window systems of the earlier version of this work on which it was run, and the figure data (illustration only).

Requirements: Python 3, a C++17 compiler.

Last run 2026-10-29: PASS, 0.8 s (verifier, see `verify/README.md`) + 2.7 s (compilation and pipeline) (one core).
